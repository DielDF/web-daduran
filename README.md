This is my site to be used as a technical showcase. I built it based around React and Node.js, using Typescript as it is very comfortable for me to use.

I deployed this site using Namecheap and Vercel, and had to maneuver around cybersecurity due to recent circumstances.

It's structure follows a typical Node.js site, with all main components being on the app folder,  although the API for the projects is stored on another folder outside the components for ease of use.

I consider it finished, however I may make small adjustments based on feedback. Thanks for reviewing.
